# Radio Shack 📻

An online radio player streaming lossless FLAC audio. Built for local prototyping with Express + SQLite — no bundler, no framework, just vanilla JS.

---

## Features

- **Lossless HLS playback** via [hls.js](https://github.com/video-dev/hls.js), locked to the FLAC rendition of the stream
- **Live now-playing** — artist, title, album art, source/stream quality, polled every 20 s
- **Per-track ratings** (👍 / 👎) — one vote per browser identity, changeable; voter ID derived server-side from IP + User-Agent hash so no login is required
- **Previously played** — last 5 tracks from the metadata feed
- **Stations CRUD** — add and remove stream stations, persisted in SQLite
- **Dark / light mode** — class-based toggle with system-preference detection and no flash on load

## Stack

| Layer | Technology |
|---|---|
| Server | Node.js ≥ 22.5, Express 4 |
| Database | SQLite via built-in `node:sqlite` (no native compilation) |
| Styles | Tailwind CSS v4 CLI, Radio Shack brand theme |
| Frontend | Vanilla JS ES modules (no bundler), hls.js via CDN |
| Testing | Vitest — node environment for server, jsdom for UI |

## Getting Started

**Prerequisites:** Node.js ≥ 22.5. Use [nvm](https://github.com/nvm-sh/nvm):

```bash
nvm use          # picks up .nvmrc → lts/*
```

**Install and run:**

```bash
npm install
npm run dev      # Tailwind watch + nodemon in one terminal
```

Then open http://localhost:3000.

`npm start` is the production-style command — it builds CSS once then starts the server without file watching.

## Scripts

| Script | What it does |

## API

| Method | Path | Description |
|---|---|---|
| GET | `/api/health` | Liveness check |
| GET | `/api/stations` | List all stations |
| POST | `/api/stations` | Create station — body: `{ name, stream_url, genre? }` |
| DELETE | `/api/stations/:id` | Delete station |
| GET | `/api/ratings?track_key=` | Get `{ up, down, user_vote }` for a track |
| POST | `/api/ratings` | Submit rating — body: `{ track_key, rating: 1 \| -1 }` |

Voter identity is computed server-side as `SHA-256(VOTER_SALT | ip | user-agent)` — no client storage required. Set the `VOTER_SALT` environment variable in production. Behind a reverse proxy, add `app.set('trust proxy', 1)` to `server.js` so `req.ip` resolves correctly.

## Stream

The default stream is a lossless FLAC HLS feed. Its master playlist exposes two renditions:

| Rendition | Codec | Quality |
|---|---|---|
| `flac_hires.m3u8` | `fLaC` | 16-bit / 44.1 kHz lossless ← player pins here |
| `aac_hifi.m3u8` | `mp4a.40.2` | AAC HiFi |

Now-playing metadata and cover art are fetched directly from the same CDN origin (`metadatav2.json`, `cover.jpg`). Both endpoints send `Access-Control-Allow-Origin: *`.
